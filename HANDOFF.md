# MyNotch — Handoff (2026-10-15)

## Goal
Write our own version of BuildNotch (https://www.buildnotch.app/), a Windows 10/11 "notch" overlay that sits at the top of the screen, expands on hover (or when pinned), and hosts developer-oriented widgets.

BuildNotch's feature set (reference for future milestones):
- Music/media playback controls
- Focus timers (8 visual themes: Clean, Pixel, Dusk, Dots, Retro Clock, Focus Terminal, Zen, Cyber HUD)
- Tasks and quick notes per project
- AI app detection/launching (ChatGPT, Claude, Cursor, Antigravity) and daily/weekly AI usage tracking
- GitHub contribution activity
- Code snippet playground (auto-saves locally)
- Clipboard history (text, code, images, links)
- App shortcuts, inspirational quotes
- Live CPU / RAM / network stats

## Decisions made
- **Language/UI:** native Rust + `windows` crate (0.62) + Direct2D/DirectWrite. No web view, no GUI framework.
- **Milestone 1 scope:** overlay shell + live system stats (CPU/RAM). Proves the hard part (transparent, always-on-top, hover-animated window) first.
- **Milestone 2 scope:** widget system + media controls (SMTC). The System stats moved onto the widget system.
- **Polish pass (after M2):** obsidian glass look, fullscreen auto-hide, Start with Windows, saved settings, network speed, single instance. Done before adding more widgets.
- **Milestone 3:** Pomodoro focus timer widget + a runtime-drawn, theme-aware tray icon.
- **Milestone 4:** bigger notch (720 × 240) with a Home dashboard + tabs; album art, progress and seeking in Media; app shortcuts; clipboard history. (The user's picks.)
- **After M4 (user requests):** unpin apps straight from the Apps grid; a Clock tab with seconds; icon tabs drawn as outlined tabs; slide the notch along the top edge; a Settings tab (gear) for body colour and opacity.
- **Second round:** Clock and Focus merged into one **Time** tab (clock left, focus middle, a new stopwatch right); a 5-minute-step slider for the focus length beside the 15/25/50 chips; drag pinned apps to reorder them.
- **Phase 1 (typing, global shortcut, app search):** planned in `docs/Features/MyNotch/roadmap.md` (Phases 1–5) and `docs/Features/MyNotch/Tasks/Phase-1-Overview.md` (decisions P1-D1 to P1-D13). The search bar sits in the tab row; the global shortcut defaults to **Ctrl+Alt+K** and is changed by recording it in the Settings tab; the notch takes keyboard focus only after an explicit click or the shortcut, and gives it back. (The plan said Ctrl+Alt+Space, but Claude desktop owns that combination on the dev PC, so the user chose Ctrl+Alt+K on 2026-10-15.)

- **Halo glass look (2026-10-16, from the user's "Orbit / Halo glass" reference):** translucent midnight-blue glass (`#081624`) over a real DWM blur, cyan–violet edge lighting, Rajdhani 500 for the clock/timer/stopwatch numbers (bundled), Segoe UI Variable for the rest, a 44 px toolbar with a lit open tab, the timer's play/pause inside a progress ring with four session segments, and 150–200 ms transitions that follow Windows' animation setting. The window shrank to 720 × 210; every panel was re-fitted. Style values live in `src/theme.rs`.
- **Time tab rearranged, weather (2026-10-16, user requests):** Timer (the focus timer, renamed) on the left, Local Time in the middle, Stopwatch on the right. The clock card shows the sun by day and the moon (in its real phase) by night, and the local temperature and sky. The place is typed in Settings (city or ZIP; the user chose that over Windows location or IP lookup). Weather comes from Open-Meteo (free, no key) over WinHTTP.
- **Simpler timer, running cues (2026-10-16, user requests):** the Pomodoro cycle (breaks, sessions, skip, "01 / 04") was dropped for a single countdown, since the user runs one timer and found skip confusing. The Timer card got narrower and Local Time wider. While the Timer or Stopwatch runs, a light runs round its card and its own indicator (the ring's end, the stopwatch's sweep) breathes.
- **Timer styles (2026-10-16, user request, the first of the "timer extras"):** eight looks for the Timer card, named after BuildNotch's themes (its site gives only names, so the looks are ours): Halo (the default, unchanged), Pixel, Dusk, Dots, Retro Clock, Terminal, Zen and Cyber HUD. Picked from a gallery opened by a palette button on the Timer card; Settings has no room for a sixth row. The stopwatch keeps the Halo look. The other extras discussed (a timer that survives a restart, +5 min while running, a label, stopwatch laps, start/pause shortcuts) are not done.

## Current state — after the Halo look (on `main`; M4 is `9dd152c`, post-M4 polish `63f6951`, Phase 1 the commits after it, then the Halo look)
Builds clean (`cargo build`, `cargo clippy --all-targets`: no warnings; `cargo test`: 80 passing). A release build is left running from `target\release\mynotch.exe`, so debug `cargo build` isn't blocked by a locked exe. Quit it from the menu before `cargo build --release` or `cargo run`; the single-instance guard makes a second copy exit at once.

**What it does.** The collapsed notch (270 × 32) is a rail: the time to the minute (Rajdhani) and, once there's weather, the sky icon (the sun or moon when clear) and the temperature on the left, then the top widget's readout: a running timer ("● Timer 24:13", the dot breathing while it runs, with a progress hairline along the bottom), else the current track while media plays (also with progress), else a paused timer, else CPU/RAM. Hovering opens it (720 × 210). The toolbar (44 px, over a hairline) has the brand mark (a lit ring with a violet planet) and a divider, icon tabs **Home, Media, Time, Apps, Clipboard, System**, and on the right a **magnifier**, **Settings** (gear) and the pin. The open tab is lit cyan glass with a glowing underline and widens to show its name (`tab_rects`; the width eases, nudging the tabs after it). The empty stretch shows the hovered tab's name and a six-dot grip; the magnifier sits at its right end, and the drag handle stops just before it. Opening goes to Home if that's where you left it; otherwise to live activity (running timer or playing media); otherwise to the last tab you picked. Settings is never reopened by itself.
- **Sliding:** drag the empty stretch of the tab row (↔ cursor there). The position is saved as a fraction of the monitor width (`position`, 0 = collapsed notch flush left, 1 = flush right, 0.5 = centre), so it survives resolution changes. Collapsed and expanded centre on the same point, except that the expanded notch keeps its shadow on-screen (`edges()`), so near an edge it stops while the collapsed pill carries on to the edge. A drag that ends within 12 px of the middle snaps to it. The notch is never the foreground window, so mouse capture only sees the cursor over the window; the frame timer also follows the drag and ends it when the physical button is up (`primary_button_down`, which honours swapped buttons).
- **Search:** clicking the magnifier turns the whole stretch into a text field and takes the keyboard (the notch becomes the foreground window).
  - Editing: Left/Right (Ctrl for words), Home/End, Shift to select, Backspace/Delete (Ctrl for words), Ctrl+A, cut/copy/paste (Ctrl+X/C/V, Shift+Delete, Ctrl/Shift+Insert), click to place the caret (Shift+click extends). Pasted line breaks become spaces; at most 100 characters. Copies made from the field go into Clipboard history. The caret blinks at the system rate; the I-beam shows over the field.
  - Results replace the panel: an empty query shows the pinned apps; otherwise every installed app that matches, ranked by tier (name prefix, then word prefix, then initials, then substring), then pinned first, then shorter name, then alphabetical. Down/Up/Tab move the highlight (the list follows it), the wheel scrolls, and Enter or a click launches the app and lets it come to the front. No match shows `No apps match "…"`.
  - Esc, clicking a tab, Alt+F4 or the shortcut again close search and give the foreground back to the window that had it. Clicking another window closes search too. While searching the notch stays open even with the cursor away.
- **Global shortcut** (default **Ctrl+Alt+K**): opens search from any app, and closes it again if pressed while searching. It also works over a fullscreen app: the hidden notch comes back for the search and hides again afterwards. Registered with `RegisterHotKey` (`MOD_NOREPEAT`); if another app owns the combination, the Settings row says so and MyNotch carries on.
- **Settings:** ten colour presets (Halo default, Obsidian, Graphite, Slate, Navy, Ocean, Forest, Plum, Wine, Ember) and a custom swatch that opens Windows' colour picker (`ChooseColorW` with a hook). The picker opens centred under the notch, previews each colour on the notch live (from the dialog's R/G/B boxes' `EN_CHANGE`), and Cancel goes back. Its custom-colour slots start as the presets. Opacity is a slider from 10–100% in 5% steps (the wheel works over it too). It scales the body, sheen, glow and shadow, not the content or the rim. A Center button resets the position. A fourth row, **Shortcut**, shows the current shortcut on a chip: click it and press a new combination (Win, or at least two of Ctrl/Alt/Shift, plus a letter, digit, F-key or one of the named keys); Esc cancels, Backspace or Delete clears it ("None"), and anything else (Shift+A, Ctrl+C, Alt+F4, a modifier alone) is ignored while it keeps waiting. Clicking anywhere else stops recording and keeps the old one. A conflict shows "Taken by another app" in amber. While recording, the chip is lit (cyan glass). A fifth row, **Weather**, is a text field for a city or ZIP code: click it (the saved one comes up selected) and type; Enter saves and looks it up, Esc or clicking elsewhere leaves it unsaved, and an empty field turns the weather off. Beside it: the place found ("Lexington, South Carolina"), "Looking it up…", "No place found by that name" (amber), or that the service can't be reached. The rows are 29 px apart so five fit the 146 px panel; their labels are small caps. The opacity is the glass tint's (60% by default); the tint is drawn a little denser than that (×1.1 at the top to ×1.18 at the bottom) so text stays readable over a bright wallpaper. A settings file from before the Halo look whose colour is still the old default (obsidian `0B0912`) moves to Halo at 60% once; the file then carries `style=halo` (unit-tested).
- **Time tab:** three cards, Timer / Local Time / Stopwatch, sized 34/36/30% (`time::cards`), each a darker layer of the glass with a hairline edge lit along its top; the Timer card is edged in its style's colour (brighter while it runs), the Stopwatch card in cyan while it runs. While either runs, a comet of light runs round its card once a second, easing in and out of each lap (slow at the start and finish, fast round the far side) with its tail stretching as it speeds up (`Canvas::runner`, `widgets::running_edge`; with animations off the lit edge alone says so). Each has a small-caps header.
  - **Timer:** see Focus below.
  - **Local Time** (`clock.rs`): the header's icon is the sun by day and the moon by night, drawn in its real phase (`weather::moon_age`, from the mean synodic month; mirrored south of the equator), and the right of the header has the temperature (°F with US regional units, else °C) with a small sky icon (cloud, sun or moon behind a cloud, rain, snow, lightning, fog, or wind when it's windy and dry; none when clear, since the sun or moon is already there; `sky.rs`). `h:mm` in Rajdhani 48, centred, with `:ss` smaller and AM/PM in small caps, or `HH:mm` if the user's regional setting is 24-hour (`LOCALE_ITIME`). Below: the weekday (`dddd`) left and month-day right, using the locale's `LOCALE_SMONTHDAY` picture (`DATE_MONTHDAY` fails with error 87 on this machine); the sky in words ("Partly cloudy · Windy"), or "Add your city in Settings", "Getting the weather…", "Couldn't find that place", "Weather unavailable"; then a hairline lit for how far through the day (gold, sunrise to sunset) or night (violet) it is. Day and night come from the place's sunrises and sunsets (yesterday to tomorrow, so midnight works); with no weather, 6:00–18:00. It always shows seconds, whatever the user's long time format says.
  - **Stopwatch:** `mm:ss` in Rajdhani 32 with `.t` smaller (`h:mm:ss` past an hour), a hairline under it swept by a light through each minute (breathing while it runs, dimmed when paused), a Start / Pause / Resume button (lit while running) and reset (disabled at zero); "Paused" in the header. In the collapsed notch: running, priority 8 and live; paused, priority 4.
- **Home:** cards side by side, weighted by `card_weight()`: now playing (art, title, progress, transport), focus (lit; time, status, session segments, controls) and system (CPU/RAM bars, NET).
- **Media:** album art up to 140 px (decoded with WIC on the media thread, fetched once per track with a few retries), title/artist/app, a progress bar with elapsed/total (position extrapolated from the app's last timeline report), click-to-seek, previous/play-pause/next.
- **Focus** (`focus.rs`: the Time tab's **Timer** card on the left, and a Home card): a single countdown (`timer.rs`).
  - The card shows "• Timer", the time left in Rajdhani 32 (the stopwatch's size) with a status line ("Ready", "Ends at 11:55 AM", "Paused", "Time's up"), and on the right start/pause inside a ring showing the time left (cyan into violet; dimmed while paused) whose moving end carries a bright point that breathes while it runs, with reset under it. Home's card: the time, the status, a time-left bar (its end breathing while it runs), reset and start/pause.
  - Starting the timer (or the stopwatch) sends out one soft pulse, unless animations are off.
  - **Styles** (`styles.rs`, saved as `timer_style`): each draws the time, the ring, Home's bar and the running cue its own way, and lights the card, the header dot and the start/pause button in its colour. Chips, slider and reset stay as they are.
    - **Halo:** as above. **Pixel:** chunky 3×5 pink pixel digits over a violet drop shadow (whole-px blocks, filled as one shape so they stay crisp), a ring of 16 blocks whose last one blinks yellow while it runs, a block bar, and a light that hops round the card in 16 steps. **Dusk:** cream Rajdhani, the ring in a sunset gradient (amber, coral, violet; `Canvas::ring_gradient`) with a low sun at its end, a gradient bar. **Dots:** 5×7 LED dot-matrix digits with the unlit dots faintly there, a ring of 40 dots in violet, a dotted bar.
    - **Retro Clock:** each digit on a charcoal flip tile; when a digit changes it flips over in 340 ms (the old top half falls on its hinge, the new bottom half lands; `Canvas::squashed`), worked out from the time alone (`Focus::flip`), so nothing is stored; an amber ring with twelve kitchen-timer marks outside it, an amber bar with quarter marks. **Terminal:** green Cascadia Mono (Consolas if missing) with a faint phosphor glow and a block cursor that blinks while it runs, "# ends at 4:05 pm", a dashed ring, an ASCII bar `[#####-----]`. **Zen:** soft white digits, a hairline sage ring whose end breathes slowly (8 s), and instead of the running light the card's edge breathes. **Cyber HUD:** slanted seven-segment digits in cyan with the unlit segments faintly there, in corner brackets; the status in small caps; a ring of 48 ticks with the end marked in magenta and a magenta scanner sweeping round outside while it runs; a tick bar.
    - **Gallery** (`gallery.rs`): the palette button at the Timer card's top right replaces the Time tab with a "Timer style" panel: eight tiles, four to a row, each showing the timer as it stands (stopped, its ring is drawn 70% full to show it off) in its style, the chosen one lit with a ✓. A click picks one and closes it; × closes it. It also closes when the notch closes or another tab opens (`Widget::leave`).
  - The length is set with chips (15m/25m/45m; 45 replaced 50 to match the reference) or a slider from 5 to 180 min in 5 min steps (`minutes_at`, unit-tested) along the card's bottom, and saved as `focus_minutes`.
  - Chips and slider work only while the timer is stopped; otherwise they're greyed out.
  - When it reaches zero it stops ("Time's up", ready to run again), the notch pops open for 6 s and plays `Notification.Reminder`. In the collapsed notch: running, priority 20 and live ("Timer 24:13"); paused, priority 5.
- **Apps:** pinned apps from Windows' full app list (`shell:AppsFolder`: desktop and Store apps) with their real icons.
  - Click to launch; it launches on release.
  - Drag a pinned app to reorder: past 6 px it lifts and follows the cursor, the others shift live, and the order is saved on release (`reorder`, unit-tested; pinned-but-uninstalled apps keep their places).
  - Hovering a pinned app shows a × badge (red under the cursor) that unpins it. "+" opens a scrollable picker of every installed app (pinned ones carry a blue ✓): click to pin or unpin, "Done" to close. First run pre-pins installed common apps (`apps::SUGGESTED`). Pins are saved as `apps=` in settings.
- **Clipboard:** the last 30 copies (text, links, images with thumbnails), newest first, in memory only; click to copy one back ("Copied"); the trash button clears. Copies marked private (`ExcludeClipboardContentFromMonitorProcessing`, `Clipboard Viewer Ignore`, `CanIncludeInClipboardHistory` = 0, as set by password managers) are skipped. Reading waits 150 ms after each change, so it doesn't collide with apps still publishing their data.
- **System:** CPU, RAM and NET with 60-second history graphs.
- **Tray icon:** drawn at runtime (`icon.rs`) at the DPI-correct size, white or near-black to match the taskbar theme, with a blue-violet notch. Redrawn on theme/DPI change and Explorer restart.
- **Look (Halo glass):** midnight-blue tint over a real blur of what's behind (see How it works), lit along its top edge in cyan into violet, with a cyan-to-violet hairline rim, a fainter inner hairline, faint cyan/violet blooms and a soft blue-black shadow. Text `#EAF7FF`, secondary `#A8C3D5`, accent cyan `#91EAFF`, violet `#B3A2FB` (all in `theme.rs`). The strongest glow is on the open tab and the timer's ring. Hover and state changes ease over 160–190 ms (`motion.rs`); with Windows' animation effects off they jump, nothing pulses, and opening/closing is instant. With transparency effects off the glass is solid and nothing is blurred.
- **Menu** (right-click the notch or the tray icon): Pin open, Hide over fullscreen apps (default on), Start with Windows (default off; `HKCU\...\Run\MyNotch`), Quit.
- **Settings** in `%APPDATA%\MyNotch\settings.ini`: `pinned`, `hide_in_fullscreen`, `tab`, `focus_minutes`, `apps`, `color` (`RRGGBB`), `opacity` (percent), `position` (0..1), `hotkey` (e.g. `Ctrl+Alt+K`; empty = no shortcut; missing or unreadable = the default), `style` (`halo`; see Settings), `timer_style` (`halo`, `pixel`, `dusk`, `dots`, `retro`, `terminal`, `zen` or `hud`; anything else is Halo), `place` (the city or ZIP as typed) with `place_name`/`place_lat`/`place_lon` once found (so startup needs no lookup). The mouse wheel scrolls the Apps and Clipboard lists.

### How it works
- Layered window (`WS_EX_LAYERED | TOPMOST | TOOLWINDOW | NOACTIVATE`) sized to the expanded footprint plus `SHADOW` (22 px). Position, size and fade alpha are applied by `UpdateLayeredWindow` on every render.
- Blur: DWM can't blur behind a per-pixel-alpha window's shape, so `Backdrop` is a second layered, click-through, topmost window kept just below the notch (`SetWindowPos` after it) and inside the body (`blur_rect`: 3 px in, extended above the screen when no monitor is there, and inside both this frame's and next frame's body so a frame of lag never shows past the glass). It asks DWM for the accent blur and lets DWM round its corners (8 px, inside the glass's 18). It hides while the notch fades or hides, with transparency effects off, and at 100% opacity.
- Click-through: the frame timer toggles `WS_EX_TRANSPARENT` so the window takes clicks only while the cursor is inside the body shape (`in_notch`).
- Keyboard focus: a click still never activates the window (`WS_EX_NOACTIVATE`, `MA_NOACTIVATE`). Only the magnifier, the Shortcut chip or the global shortcut take the foreground, explicitly (`begin_typing`), remembering the window that had it. Esc, a tab click or the shortcut again give it back (`end_typing(true)`); `WA_INACTIVE` (the user clicked elsewhere) and a launch let go without restoring. The process that receives a `WM_HOTKEY` is allowed to take the foreground, which is how the shortcut works from any app. While recording, the shortcut is unregistered so even the current combination arrives as keys, and `WM_SYSCHAR`/`WM_SYSKEYUP` are swallowed so Alt doesn't open the system menu.
- Fullscreen: every 500 ms the foreground window is checked; the notch fades out and hides, then returns.
- Rendering: `ID2D1DCRenderTarget` on a DIB; `Brushes` and `ImageCache` are rebuilt or cleared on `D2DERR_RECREATE_TARGET`. Images cross threads as `Arc<Image>` (premultiplied BGRA) and become D2D bitmaps lazily.
- Workers: media (MTA, WinRT), apps (STA, shell) and launches (short-lived STA threads) never block the UI. Clipboard capture runs on the UI thread through its own message-only window.
- Widgets work in logical units; the shell persists widget preferences (`store`) after clicks and updates.
- Animation: frames are drawn only when something changes, except while a running timer or stopwatch is on screen (its tab, Home's timer card, or the rail's live dot; `App::animating`, from `Widget::animating`/`card_animating`): then every frame tick (about 60 fps, for the fast light round a card), or every other one for the rail's breathing dot alone. That costs about 5% of one core in the release build on the dev PC (0.9% otherwise). Never with animations off. The timer styles were timed offscreen against Halo (whole Time tab plus Home's card, release build, 2× scale): all within about 1–1.5× Halo's frame time. Two early versions were twice as slow and were changed: Terminal's glow drew each digit five times (now whole lines, `Canvas::text_at`), and Dots' glow stroked every lit dot (now a fill of larger dots).
- `App` is dropped explicitly after the message loop.

## To resume
Quit the running release instance (right-click the notch or the tray icon -> Quit), then `cargo run`.

## Known rough edges / next steps
- Update the regression scripts for the 720 × 210 layout and re-run them. (Toolbar since the Halo look: 32 × 30 tabs from x = 60 at y = 7, pitch 34, the open one widened by its name (`tab_rects`); Settings tab at x = 640, pin at 674; the magnifier at x 606–638, so the slide handle is x 332–604. Content starts at y = 52, 692 × 146.)
- Apps: dragging doesn't scroll the grid, so an app can only be dropped on the visible rows.
- Look: light custom colours make the white content hard to read; text doesn't switch to dark.
- Sliding: near an edge the expanded notch stops while the pill's position keeps moving, which you only see once it collapses.
- Apps: the app list loads once per launch, so newly installed apps appear after a restart (in search too).
- Text field: no undo, no drag-selection or double-click selection; the IME composition window isn't positioned; emoji draw in monochrome (Direct2D colour fonts aren't enabled).
- Shortcut: key names are US-layout labels; some Win+ combinations are taken by the shell before MyNotch sees them, so they can't be recorded; two-modifier combinations that apps rely on (e.g. Ctrl+Shift+T) can still be recorded. On the dev PC Ctrl+Alt+Space belongs to Claude desktop.
- Clipboard: history is lost on restart (by design, for privacy); only text and bitmaps are kept (no files or rich formats); very large images are converted on the UI thread.
- Media: seeking's effect is unverified; it still polls instead of subscribing to SMTC events.
- Start with Windows registers whichever exe was running when it was ticked; a proper install location would make that stable.
- The blur relies on `SetWindowCompositionAttribute`, which is undocumented (stable since Windows 10); without it the glass is just tinted. With a monitor directly above the primary, the blur's top corners are rounded too, leaving two tiny unblurred corners at the screen's top edge.
- The tray icon is still the older blue-violet notch, not the Halo mark.
- Network throughput can double-count virtual adapters (VPN, WSL).
- Weather: WinRT's `HttpClient` (WinINet) fails Open-Meteo's TLS on the dev PC with 0x80072F8F although the certificate is valid (curl, .NET and WinHTTP accept it, revocation checked), hence WinHTTP. Units follow the regional setting, with no toggle. Refreshes every 20 minutes; there's no forecast, only now.
- Primary monitor only. The exe itself has no embedded icon.
- Timer: a running timer or stopwatch doesn't survive a restart (or a rebuild that restarts MyNotch). The styles apply to the timer only, not the stopwatch. The gallery has no keyboard (Esc doesn't close it). Chips, slider and reset stay cyan in every style.
- Repo: `origin` = github.com/ContactEstablished/mynotch, default branch `main`.
- Next features: the roadmap's Phase 2 (Live Status: `mynotch status "…"` from scripts, forwarded to the running notch), Phase 3 (a local API in Signal), Phase 4 (Agenda, Tasks and Notes from Signal), Phase 5 (mic/camera dot, volume HUD, battery). The text field exists now (`src/text.rs`); fields inside widgets come with Phase 4. Still open for later: AI-app tracker, GitHub activity, code playground, and the other timer extras (survive a restart, +5 min, a label, stopwatch laps, shortcuts).
